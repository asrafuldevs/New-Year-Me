# New-Year-Me

A simple, responsive landing page project built with HTML and CSS based on the **"New Year, New Me"** theme.

## Project Overview

This project presents a motivational single-page website that includes:

- A hero section with a strong headline and call-to-action
- A "failures of previous year" reflection section
- A goals/plans section for the new year
- A positive mindset callout banner
- A footer with contact and subscribe areas

## Built With

- HTML5
- CSS3
